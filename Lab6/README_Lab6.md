# ARTI308 Lab 6

This folder contains the completed Lab 6 files for the **Linear Regression** task.

## Files
- `ARTI308_Lab6_Completed.ipynb` : completed notebook
- `Ecommerce Customers.csv` : dataset used for the task
- `USA_Housing.csv` : original dataset used in the lab examples

## What is included
- Data loading
- Data exploration (`head`, `info`, `describe`)
- Basic data cleaning checks
- Feature preparation
- Linear Regression model training
- Model evaluation using:
  - MAE
  - MSE
  - RMSE
  - R²
- Visualization of predictions and residuals
