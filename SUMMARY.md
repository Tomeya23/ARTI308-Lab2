# Summary – ARTI308 Lab 2

## Dataset Description
The dataset used in this lab is the well-known Iris Dataset, which contains measurements of three Iris flower species.  
It includes 150 samples and 5 columns: four numerical features and one target label.

### Features:
- sepal_length
- sepal_width
- petal_length
- petal_width

### Target Variable:
- species  
  - Possible classes: setosa, versicolor, virginica

The dataset was loaded from the file iris.csv included in the repository.

---

## Machine Learning Problem Type
This project represents a Classification Problem.  
The goal is to predict the species of an Iris flower based on its numerical measurements.

---

## Problem Statement
The purpose of this lab is to build a simple machine‑learning workflow using the Iris dataset.  
The objective is to classify each flower sample into one of three species by learning the relationship between the four numerical measurements and the target class.  
This workflow demonstrates essential ML steps such as data loading, inspection, and methodology planning.
